# Modelo de Domínio - TechStore

Esta pasta contém a documentação das entidades de domínio do sistema TechStore.

O modelo de domínio representa os principais conceitos do negócio, seus atributos, regras relacionadas e relacionamentos entre entidades.

## Entidades

- Produto
- Categoria
- Estoque
- Usuário
- Cliente
- Endereço
- Carrinho
- Pedido
- Pagamento
- Devolução

## Documentação

Cada entidade possui seu próprio arquivo contendo:

- Descrição da entidade.
- Atributos principais.
- Regras de negócio relacionadas.
- Relacionamentos com outras entidades.

## Objetivo

Documentar a estrutura do domínio antes da implementação do sistema, servindo como referência para as próximas etapas de modelagem e desenvolvimento.
